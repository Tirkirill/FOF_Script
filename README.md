# FOF Script

Это простое приложение на Python, которое позволяет удобно создавать .txt-файлы скриптов ботов для игры Fistful of Frags.

Программа позволяет выбрать начальное оружие для ботов (или сделать его случайным), а также генерирует другие случайные характеристики. Результирующий файл можно сразу использовать в игре.

Структура проекта
├── CONSTS.py             # Константы проекта: список имён, оружие и т.п.
├── generating_script.py  # Основная логика генерации скрипта
├── main.py               # GUI-приложение на tkinter
├── new_script.txt        # Пример сгенерированного скрипта

Нажмите "Готово", и в папке появится файл new_script.txt, который можно использовать в игре (для этого надо поместить его в Fistful of Frags\fof\fof_scripts\bots) и выбрать при создании сервера
